КАК ЗАПУСТИТЬ У СЕБЯ
================================================================================

1) Положи CSV-файлы в папку со скриптом (рядом с hybrid_backtest.py):
     EURUSD_M5_202504180935_202608271920.csv
     EURUSD_H1_202401020000_202608271900.csv
     EURUSD_H4_202401020000_202608271600.csv
     EURUSD_Daily_202401020000_202608270000.csv

2) Установи зависимости (один раз):
     pip install lightgbm scipy

3) Запуск:
     python hybrid_backtest.py

   Всё: авто-пути, Supertrend, фичи, обучение LGBM (Walk-Forward),
   3 варианта A/B/C, графики (chart_hybrid.png).

   Если CSV лежат в ДРУГОЙ папке - раскомментируй в начале скрипта:
     DATA = r"D:\ПУТЬ\К\ПАПКЕ\С\CSV"


ПАРАМЕТРЫ (в начале скрипта)
================================================================================
  ATR_PERIOD=10, ATR_MULTIPLIER=3.0   - Supertrend (как в твоём MQL5)
  LOT_SIZE=0.01                        - базовый лот
  INITIAL_BALANCE=10000                - стартовый депозит
  TP_PERCENT=1.0                       - баскет TP (+1% от баланса)
  MAX_RISK_PERCENT=15.0                - Global SL (было 99% -> стало 15%!)
  MAX_POSITIONS_PER_SIDE=25             - макс лотов в одном баскете
  TRAIN_BARS=4000, TEST_BARS=500       - окна Walk-Forward
  SIGMA=5, LGBM_THRESHOLD=0.0          - производная Гаусса + порог LGBM


ФАЙЛЫ
================================================================================
  hybrid_backtest.py  - основной скрипт (запускай его)
  test_load.py        - тест чтения CSV + Supertrend (если что-то пойдёт не так)
  test_paths.py       - тест авто-путей к файлам
  chart_hybrid.png    - результат теста в песочнице (пример)
